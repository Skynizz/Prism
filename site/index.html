What it does

Every layer. One tool.

Prism reads what each game actually ships — engine, API, DLSS runtimes, Streamline — and installs the right stack for your GPU.

DLSS 5

Neural rendering, injected.

On DirectX 12, OptiScaler DLSS 5 in one click: the neural pass inside the game's pipeline for a fraction of its usual cost, no ReShade needed. Or the RenoDX DLSS package with DLSS 310.9.1 and Streamline 2.14.1. The neural runtime is matched to your GPU and every NVIDIA file is checked before it is written. The recommended path is picked for your game.

Injection

The whole pipeline, on one screen.

Game, engine, API, DLSS Super Resolution, Frame Generation, Multi Frame Generation, Ray Reconstruction, DLSS 5 and HDR — read from the game itself, so you see exactly what runs.

Multi Frame Generation

Up to ×6.

Paths filtered by GPU generation: native MFG on RTX 50, RenoDX MFG Unlock ×2–×6 on RTX 40, ported DLSS-G on RTX 30 and 20. Games without frame generation get it through OptiScaler.

Nexus Mods

Nexus Mods, built in.

Browse Nexus inside Prism. Click download and every file lands in the right folder. Requirements are found — and their requirements — then Download all gets them. Premium members download in the background.

Mod health

Frameworks your mods depend on, files that went missing, conflicts, and the errors loaders wrote at your last launch. Each problem comes with its fix. It checks again after every install and when the game closes.

Questions

Windows says “Windows protected your PC”.

Prism is not code-signed yet, so SmartScreen warns about a new download. It is only a warning: More info → Run anyway, after checking the file against its SHA-256. Smart App Control, if enabled, blocks unsigned apps outright; a code-signed release fixes that.

Does Prism include NVIDIA or third-party files?

No. Each component is downloaded from its official public source at install time, verified, and recorded.

Can I go back to the original game files?

Yes. Remove undoes one install; Restore vanilla undoes everything Prism did to a game. Backups survive uninstalling Prism.

Why does Prism ask for administrator rights?

Many games live under Program Files, where replacing DLLs needs elevation. The installer itself does not.

Is it safe with online games?

Don't use overlays in multiplayer games with anti-cheat. Prism is meant for single-player games.

Is it really free?

Yes. Prism is open source under the GPL-3.0 license. No Prism account, no paid tier.
